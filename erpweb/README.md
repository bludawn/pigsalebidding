    * 是否需要审计字段，如创建人、创建时间、更新人、更新时间    
    * 数据隔离，如所有模型上都有 组织字段，根据组织隔离数据
    * 接口规范，默认为restful
    用户澄清了以上内容后，要写入到code_rule_memory.md文件。  
    确保以上规范内容在code_rule_memory.md存在，并且你已经非常清楚要怎么做，如果用户有其他规范，你也可以放进去。

## 模型
* 每个模型都有一个模型id名称，唯一
* 模型有 基础模型、业务模型、树形模型、快照模型
* 所有模型都有 id字段
* 基础模型 有 数据状态，枚举值， 有效和失效;有编码字段；
* 业务模型 在基础模型 基础上， 有 审批状态，枚举值， 审批中、审批通过、被驳回
* 树形模型 在基础模型 基础上，有 上一级id，全路径id 通过.隔开、全路径编码（如果有）、全路径名称（如果有）
* 快照模型 在 基础模型、业务模型、树形模型 物理表外，新增一个表，其中boid 字段 是 原数据表的id，除id所有其他字段都一样，每次修改 且数据有变化（不含审计字段）都会有一条快照数据，每次删除，都会新增一条；新增一个快照时间字段，记录新增时间。
* 用户一般在以上4种模型中能满足，如果用户有其他模型需求，你也可以询问用户并实现。
* 模型内，有分录，新增分录表，以entry结尾；分录表中 主键为f_entryid（命名参考规范），主表id为f_id（命名参考规范），不含审计字段



### 模型-列表
* 列表上有过滤条件面板，全字段过滤条件
* 列表字段列可以冻结、拉伸、显隐，表头可以点击上下箭头排序
* 列表最后一列是操作列，有一般操作 查看、修改、删除
* 列表行数据 支持选中进行集合操作，集合操作一般有 删除、导入、导出
* 列表有新增、删除、导入、导出 按钮功能
* 列表行 如果有编码，则编码是蓝字超链接，打开的查看态表单页面。没有编码 但有名称，则名称是蓝字 超链接。用户没有指定就按这个规则，或者你询问用户。
* 列表查询，加入用户的数据权限条件
* 用户有对应权限，才能进行对应操作，否则弹出没有权限提示
* 列表都有刷新按钮
* 树形模型，显示为左树右表，左树通过缩进、展开、收起体现层级，仅显示名称字段，支持搜索；右表显示列表，和其他列表一样，但根据左树选择的节点，过滤出属于该节点以及该节点下的数据。
* 列表数据支持两种显示模型，一种是列表、一种是卡片。


### 模型-列表-过滤面板
* 过滤面板字段来源于所有模型字段，并且支持模型下面2级级联，例如 员工上面的岗位.职级字段，orm条件级联为员工表下通过岗位字段查询 position.id, position.name，转成sql时，可以是join查询
* 字段类型如果是数字、字符串，则直接输入
* 字段类型如果是id，则弹出F7选择列表，支持多选，并且反显 名称或者编码，取决于字段定义
* 字段类型如果是枚举值，则弹出下拉列表，支持多选，并且反显
* 过滤面板保存方案，可以保存当前的的查询条件，下次点击方案，可以快速填充查询条件
* 过滤面板有展开按钮，点击展开所有查询条件字段，展开后，变成收起按钮
* 过滤面板日期字段，点击打开选择开始日期和结束日期
* 过滤面板时间字段，点击打开开始时间和结束时间
* 过滤面板有高级按钮，点击后，显示一套规则引擎，所有过滤字段条件通过规则引擎来配置
  * 规则引擎由三部分组成 字段，关系，值
  * 关系一般有，大于 >，小于 <，等于 = ，大于等于≥，≤，不等于 !=，在什么中 in，不在什么中 not in，包含 like；关系，根据字段类型 显示不同，如数字 不可能有 包含 关系。
  * 值则和过滤面板字段输入框一样
  * 点击+号，新增条件，默认是and逻辑

### 模型-列表-字段
* 所有字段列宽度都可以自由拉伸
* 冻结列先第一列开始，从前往后冻结
* 所有字段支持显示隐藏
* 所有列表字段都有一个序号列，也支持显隐，不过仅仅是前端显示，没有实体字段，也就不支持排序和过滤
* 字段内容超过了列的宽度，则最后用'...'来显示，如果鼠标悬浮在上面，则弹出全部文案
* 字段是图片url，则下载图片显示预览，如果是多个，则最多并列显示5个图片，点击后查看
* 字段是视频url，则显示视频播放按钮，如果是多个，则最多并列显示5个视频按钮，点击后查看
* 字段为其他模型的id，则默认显示其他模型的名称，没有名称，则显示编码，没有编码 则显示id；如果用户没有指定，则按这套逻辑来实现，或者你询问用户；
  字段为其他模型的id，支持在列表上显示多列其他模型字段，如1列显示编码，1列显示名称等等。可以咨询用户。
* 列表字段显示金额类（单价、总价、发票、税率等）精度，默认是小数点后6位
* 字段为非金额精度，默认显示小数点后2位精度。
* 字段为整形，则没有小数点，不要科学计数显示。
* 日期字段显示格式为 yyyy-MM-dd
* 时间字段显示格式为 yyyy-MM-dd HH-mm-ss
* 列表不显示分录数据


### 模型-操作
* 所有模型都有 查询、新增、修改、删除、导入、导出 操作，查询没有对应按钮
* 列表上面都有 新增、修改、删除、导入、导出、刷新按钮
* 列内最后一列操作列，有查看、修改、删除 按钮
* 每一个操作都是一个api接口
* 查询api接口，支持自定义 select 字段、 where条件、order排序，支持分页
* 如果模型为快照模型，在操作列 有 查看历史 按钮，显示之前的快照数据
* 所有操作都要有相应操作权限
* 所有数据查询，都要有模型数据权限


### 模型-表单-查看态
* 在列表通过查看按钮、超链接、url等各种方式打开表单查看态页面
* 查看态页面 无法编辑，也不要置灰
* 查看态能查看图片、视频
* 查看态能展开分录、能分页查看分录
* 查看态字段为id，如果用户没有要求，默认显示名称，没有名称编码，没有编码显示id，跟列表一样
* 查看态字段为id，不会跟列表一样显示多个列，这里只会显示一个。
* 枚举值字段，显示名称


### 模型-表单-编辑态（新增、修改）
* 新增时，如果有表单编码字段，用户有要求如何自动生成，则按用户自动生成，没有则输入
* 修改时，自动生成的编码不能修改
* 编码为必填字段，后端要做去重校验
* 用户有要求的字段校验，提交后 后端都要校验
* 存在隔离字段时，弹出的F7都要根据表单隔离字段，对F7数据进行过滤
* 其他模型id字段，点击则输入框打开的是对应模型的F7列表，并回显名称或编码。再次打开F7，之前选中的行 依旧选中。
* 枚举值字段，点击输入框则打开的是下拉框，回显名称。再次打开下拉框，之前选中的行 依旧选中。
* 图片、视频、文件字段上传，有个大的加号（+），点击后可以传入文件，上传成功后 回显。每个回显的右上角有个x按钮，可以移除。
* 有保存和取消按钮，点击保存后 新增或修改数据。

### 模型-导入
* 导入他弹出一个页面，点击+号选择文件，支持拖入文件，显示 是否更新复选框，并且有下载模板按钮
* 除开审计字段、主表id外，所有字段都可以导入
* 支持导入分录
* 是否更新复选框 勾选后，则支持更新，否则只支持新增。
* 如果存在编码，如果数据表中也有编码的数据，则更新，不存在则新增
* 字段为其他模型id，则导入时填写其他模型的名称或编码，取决于用户字段的定义，默认是名称、然后是编码、最后是id；后台通过名称或编码，找到其他模型id并赋值，然后再更新或新增
* 字段为多选，可以考虑用逗号隔开

### 模型-导出
* 支持分录导出
* 字段为多选，导出时，可以考虑用逗号隔开
* 字段为其他模型id，导出时，转成对应其他模型的名称或者编码，基于业务取决于用户字段的定义，默认是名称、然后是编码、最后是id
* 支持导出审计字段


### 模型-F7列表
* F7列表一般是在过滤面板、表单编辑 其他模型id字段时，弹出来的列表选择页面
* F7列表一般只显示核心的字段，如编码、名称、介绍，并且过滤掉 数据状态为 失效的数据。
* F7列表支持分页、全选、点选。
* 选择数据后，再次打开F7列表，依旧选择之前的数据
* 数据隔离，弹出的F7列表，要根据表单已经选择的隔离字段（如组织）来进行过滤
